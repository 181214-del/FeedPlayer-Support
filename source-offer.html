已经验证的替换路径 / Tested replacement path

已从本次开发构建收集 112 个应用目标文件并在独立目录重新链接。对 AMSMB2 增加运行探针、对 MobileVLCKit 修改版本常量后，同时替换两库并在模拟器安装运行；进程实际读回修改标记。还读取了 9 项已加载依赖版本，与已收集源码一致。此项属于开发环境替换验证，不是完整 VLC 源码重建或正式商店发行验收。

112 application objects were relinked outside the original build. A modified AMSMB2 constructor and a changed MobileVLCKit version constant were both observed in the running simulator app. Nine runtime dependency versions matched the collected sources. This demonstrates library replacement in a development environment, not a complete VLC rebuild or final store-distribution acceptance.
