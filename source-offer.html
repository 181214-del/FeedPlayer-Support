材料范围 / Scope

这些材料对应当前固定依赖。已从归档源码和全部 47 个上游补丁完整重建 arm64 模拟器框架；新框架与官方模拟器及真机框架的 242 个 VLC 插件入口逐名一致。二进制符号和运行版本验证增强了组件覆盖证据，但未取得官方最终 link map，仍不把候选清单称为完全核实的二进制 SBOM。

An arm64 simulator framework was rebuilt from the archived sources and all 47 upstream patches. Its 242 VLC plugin entry names match both the official simulator and device frameworks. Binary-symbol and runtime-version checks provide component evidence, but the official final link map is unavailable; the candidate inventory is not a fully verified final-binary SBOM.

源码重建与替换验证 / Source rebuild and replacement verification

已从开发构建收集 112 个应用目标文件并在独立目录重新链接。第一轮同时替换增加运行探针的 AMSMB2 和修改版本常量的 MobileVLCKit，进程读回两项修改标记。第二轮使用完整源码重建的 MobileVLCKit 再次替换、重链接、签名、安装及启动；进程读回专属源码修订标记，成功初始化 libvlc 并枚举 330 个运行模块，9 项依赖版本与归档一致。这些是已完成的模拟器开发验证；真机和最终商店发行验收仍需单独完成。

112 application objects were relinked outside the original build. The initial test observed a modified AMSMB2 constructor and a changed MobileVLCKit version constant. A subsequent test replaced MobileVLCKit with the complete source rebuild, relinked, signed, installed and launched the app. The process reported the unique source changeset, initialized libvlc, enumerated 330 runtime modules, and matched nine dependency versions against the archives. These are completed simulator development tests; physical-device and final store-distribution acceptance remain separate requirements.
