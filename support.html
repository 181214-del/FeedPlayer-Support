反馈前可以准备 / Helpful details

请提供 FeedPlayer 版本、iOS/iPadOS 版本、设备型号、媒体来源类型（本地、相册、SMB 或 WebDAV），以及复现步骤。无需发送服务器密码、完整私人路径或媒体原件。应用不会自动发送日志；如需附上诊断信息，请先检查并移除敏感内容。

Include the app and system versions, device model, source type and steps to reproduce. Do not send server passwords, private full paths or original media. Logs are not sent automatically; review and redact anything you choose to share.

常用操作 / Common actions

  • 购买恢复：设置 → 恢复购买。Restore purchases in Settings.
  • 缓存清理：设置 → 清空缓存。Clear the cache in Settings.
  • 广告隐私：设置 → 购买与广告 → 广告隐私选项（适用时显示）。Advertising privacy options appear in Settings under Purchases and Ads when applicable.
  • 系统权限：设置 → 关于 → 系统权限设置。Manage permissions through system settings.
  • 退款：联系 Apple / Request through Apple。

如需公开反馈，可前往 GitHub Issues；该页面公开可见，请勿发布个人信息、凭据或敏感日志。For public feedback, use GitHub Issues without private information.
